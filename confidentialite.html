Confidentialité et stockage local

Comment THOT utilise le stockage du navigateur, les services tiers et les messages reçus par e-mail.

Votre progression dans ce navigateur

Le quiz conserve ses statistiques et sa progression dans le stockage local du navigateur. L’enquête sur la mer d’Aral y conserve séparément les pièces retenues, relations, notes, hypothèses et conclusions. Le lien « Surprends-moi » utilise le stockage de session pour éviter une répétition immédiate.

Ces données restent sur cet appareil : elles ne sont pas envoyées par le code THOT à un serveur éditorial. Elles ne sont pas synchronisées entre appareils et peuvent disparaître si vous effacez les données du navigateur. La réinitialisation de l’enquête Aral préserve les statistiques du quiz. Les réglages du navigateur permettent d’effacer les autres données du site.

Évitez de saisir des informations personnelles dans vos notes. Le code du site n’ajoute ni outil de mesure d’audience, ni publicité, ni formulaire distant de collecte.

Hébergement et liens externes

La consultation du site provoque des requêtes vers GitHub Pages. GitHub indique enregistrer les adresses IP des visiteurs pour la sécurité de son service. La présente page ne signifie donc pas qu’aucune donnée technique n’est traitée.

Collecte technique de GitHub Pages · Politique de confidentialité de GitHub.

Les sources externes et les signalements GitHub s’ouvrent sur des services tiers, qui appliquent leurs propres conditions.

Certaines images sont chargées directement depuis des services tiers, notamment Wikimedia Commons et DVIDS. Ces chargements transmettent des informations techniques aux fournisseurs, qui peuvent aussi déposer leurs propres cookies et appliquer leurs règles de confidentialité.

Signalements publics sur GitHub

Les signalements proposés sur la page de contact sont publics sur GitHub et nécessitent un compte GitHub. N’y publiez aucune information personnelle ou confidentielle. Pour une demande privée, utilisez l’adresse e-mail ci-dessous.

Messages reçus par e-mail

Vous pouvez écrire à THOT à l’adresse officielle contact.thot.culture@gmail.com. Votre adresse e-mail, le nom éventuellement associé à votre envoi, le contenu du message et les éventuelles pièces jointes sont reçus dans cette boîte Gmail. Ils servent à examiner votre demande, à y répondre et à assurer le suivi de l’échange.

Ces échanges ne sont pas publiés automatiquement sur le site ou sur GitHub. Évitez d’envoyer des données personnelles ou sensibles qui ne sont pas nécessaires au traitement de votre demande.

La messagerie est fournie par Google : la réception et le stockage des e-mails passent par Gmail, selon les règles de confidentialité de Google.

Aucune durée précise de conservation des messages n’est annoncée à ce stade ; les modalités de conservation restent à préciser. Pour toute question sur vos données ou pour demander l’accès, la rectification ou la suppression d’un échange, écrivez à cette même adresse.

Les informations réglementaires restent à compléter. L’ajout de cette adresse ne finalise pas les informations légales : la clarification demandée à GitHub concernant les obligations LCEN est toujours en attente.
