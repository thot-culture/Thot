Confidentialité et stockage local

Comment THOT utilise le stockage du navigateur et ce qui est transmis à GitHub lors de la consultation du site.

Votre progression dans ce navigateur

Le quiz conserve ses statistiques et sa progression dans le stockage local du navigateur. L’enquête sur la mer d’Aral y conserve séparément les pièces retenues, relations, notes, hypothèses et conclusions. Le lien « Surprends-moi » utilise le stockage de session pour éviter une répétition immédiate.

Ces données restent sur cet appareil : elles ne sont pas envoyées par le code THOT à un serveur éditorial. Elles ne sont pas synchronisées entre appareils et peuvent disparaître si vous effacez les données du navigateur. La réinitialisation de l’enquête Aral préserve les statistiques du quiz. Les réglages du navigateur permettent d’effacer les autres données du site.

Évitez de saisir des informations personnelles dans vos notes. Le code du site n’ajoute ni outil de mesure d’audience, ni publicité, ni formulaire distant de collecte.

Hébergement et liens externes

La consultation du site provoque des requêtes vers GitHub Pages. GitHub indique enregistrer les adresses IP des visiteurs pour la sécurité de son service. La présente page ne signifie donc pas qu’aucune donnée technique n’est traitée.

Collecte technique de GitHub Pages · Politique de confidentialité de GitHub.

Les sources externes et les signalements GitHub s’ouvrent sur des services tiers, qui appliquent leurs propres conditions.

Signalements et demandes

Les signalements proposés sur la page de contact sont publics sur GitHub. N’y publiez aucune information confidentielle. Aucun canal privé de contact ou d’exercice des droits n’est encore configuré ; sa mise en place et les informations réglementaires associées restent à valider avec le responsable du site.
